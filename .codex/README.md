# Рабочий контекст Codex

Эта папка содержит долговременный контекст проекта для ИИ-агентов:

- `rules.md` — обязательные правила работы в репозитории;
- `plans/` — планы задач и их текущий статус.

Новые устойчивые договорённости добавляйте в `rules.md`. Для значимой задачи
создавайте отдельный план в `plans/` и добавляйте на него ссылку в реестр.
