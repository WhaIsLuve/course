# Реестр планов

Создавайте здесь по одному Markdown-файлу на значимую задачу.

Шаблон имени: `yyyy-mm-dd-краткое-название.md`.

## Шаблон плана

```md
# Название задачи

## Цель

Коротко опишите ожидаемый результат.

## Шаги

- [ ] `todo` — Первый шаг.
- [ ] `todo` — Второй шаг.

## Проверка

- [ ] `todo` — Команда или ручная проверка.

## Заметки

Важные решения, ограничения и ссылки на связанные файлы.
```
